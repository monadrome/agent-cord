# 澄清撤回与修正流程调研

日期：2026-10-09。阶段 39。

## 当前缺口

阶段 38 已能记录问题选项，但错误选择只能等待模型重新问，无法由人工明确撤回。仅从活动材料过滤撤回记录会回退同题较早选择；仅清空数组会恢复旧无澄清输入 hash。这两个行为都会把未确认范围误当作当前认可。

## 取舍

复用项目的追加事实与重建投影模式，以及阶段 38 已核验的 LangGraph 人工输入/持久状态分离资料，不引入新引擎或修改原事件。ADR-0053 用未确定墓碑保持最新同题状态，保留事件来源并让模型解释撤回；人工修正与 gate 决策独立。

界面沿用已答复区和 Undo2 工具/tooltip，撤回过程中禁用、失败保留记录、成功显示已撤回与时间/来源。新轮次重新提问，避免直接改写旧模型轮次。

## 验证计划

先复现路由缺失、撤回仍为当前选择、同题回退/旧身份复活。覆盖引用、scope、并发写槽位、重复撤回、过期预期 ID/被替代选择、追加失败恢复、冷重启和下一模型/worker 输入，以及人工 gate 无新增决定。完整离线/真实 HTTP/浏览器验收后小步提交并核验远端。

## 验收结果

7 个反例先失败，最终全量 858 测试 / 64 文件、build:all/typecheck/git diff --check 通过。覆盖无回退/旧身份复活、worker checkpoint 失效、模型只接受当前撤回来源、未来/自引用、并发共享槽位、写失败恢复、旧问题输入变化仍可撤回、重复重放和新轮次同题修正。

隔离 git 工作区真实 HTTP/Playwright 模拟撤回：失败时旧答复仍有效，重试中工具禁用，只记录一次撤回；重复重放不增加事实，旧问题再次答复 409。最新快照 choice=null/status=revoked，答复前后 gate/节点退出/人工决定事实集合相同。重启保留撤回，PRD 未变、worker 调用 0、人工待审 1、doctor=true。

真实 Claude architect 仅调用一次，prompt 没有旧选择标记，工具数 0，返回明确“未确定”的 wait 并引用撤回 event_id。浏览器 1440/390/320 的失败保留/保存禁用/已撤回/来源导航通过，无溢出/pageerror；桌面/手机截图已查看无重叠。模拟操作仅在临时需求中进行，未审批原真实 Draft。

此实现是后续上下文修正，不能撤销已执行工作，不修改旧记录；仍需新协调轮次重新提出选项。运行正文、截图和临时 git 工作区不入仓库。
