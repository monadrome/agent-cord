## 回归证据

- 源码修改、新增和删除使旧测试结果失效；代码改变后重启，旧人工选择被拒绝而不落决定。
- 二进制字节、文件权限、路径和类型参与内容身份；根目录位置和扫描顺序不参与。
- 依赖、构建和运行目录排除；越界、链接、硬链接、声明缺失、IO、数量/大小/深度上限以及观察到扫描变动均拒绝。
- 文件读取失败或增长时关闭描述符；输入修复后重新扫描和验证可恢复。
- 重启时源码不可读不阻止 server 提供服务；该 run 停留等待，不能批准旧结果。

## 限制

声明范围由流程作者负责完整覆盖实际测试输入；源码身份不认证模型报告、外部 CI 身份、宿主环境和未声明依赖。未声明 inputs 的流程仍只有文档/配置身份，不证明代码一致。便携文件 API 不提供跨进程文件树原子快照，应结合隔离检出使用。
