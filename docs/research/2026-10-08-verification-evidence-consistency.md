# 验证证据一致性验收

日期：2026-10-08。范围：隔离临时工作区、真实宿主命令与 HTTP API；未批准人工 gate、未采用协调提议、未改动原开发 Draft。

## 反例与修复

最初 13 个反例复现验证门禁和协调观察的规则漂移：passed 搭配非零退出码、缺失或非法摘要、负耗时、坏最新 correlation、损坏完整事件行、外部 session 及取消事实可能导致旧成功被继续消费。

ADR-0045 引入共享结果契约、严格读取、最新结果解析及取消判定。非法最新结果阻断门禁并投影为 invalid，修复后合法结果可恢复；未知退出码仍为未知。对同一事件同时断言 gate 和协调观察，覆盖失败、恢复、重启及 REST 同键修复。

首轮全量 700/701 通过，非法源码链接恢复用例失败。确定性地在 gate.waiting 落盘后、ask 挂起前变更源码，复现重检异常使 run 永久 failed。修复后保留已建立的等待，context/提交继续 409，恢复普通文件后的合法验证可唤醒原 run，不写人工决定或节点假退出。

## 真实命令链路

宿主执行 `node --test tests/addition.test.mjs`，错误断言产生退出码 1。将该结果上报为 passed 返回 400，verification.completed 数量为 0；使用同一幂等键改为 failed 成功，重启后仍停在 escalation。

修复断言后再次获取输入身份并执行，实际退出码 0；上报 passed 后进入 human_confirm。最终只有 failed/1 与 passed/0 两个验证事实，human.decision=0、节点退出=0，session doctor=true。命令日志和事件数据只保留在临时目录。

## 边界

该验收证明结果结构和消费规则一致，不认证宿主是否如实执行外部 CI，不证明模型推断质量。严格读取不代替 doctor 哈希链检查；原子追加未完成的尾行恢复继续使用现有事件存储语义。真实开发 Draft 经实时 HTTP 核验仍为一个待审 gate、零人工决定、done 未退出。
