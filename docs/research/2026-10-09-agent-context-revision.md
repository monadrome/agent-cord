# agent 外部上下文版本调研与验收

日期：2026-10-09。阶段 40。

## 当前证据

ADR-0031 与 headless/ACP 构造器明确排除 env，已有测试证明环境值变化不改变身份。外部命名 agent 文件同样不在 argv 指纹内。隐私选择有效，但用户缺少声明行为性环境/角色变更的入口，可能继续复用旧报告或协调提议。

## 本轮取舍

使用可选正整数 context_revision，不采集任何环境原文或凭据 hash。它仅改变配置身份，复用已有恢复与当前提议核验，维持在途 resolver 固定。数字声明公开且便于控制台扫描；这不是自动环境检测，配置者必须维护。

## 验证计划

先复现 YAML 拒绝字段、原生 driver 版本不影响身份、清单缺版本与旧任务复用。验证未声明兼容、版本/环境/格式稳定性、非法值拒绝、CLI argv 不变、ACP/模板/自定义 args、固定 resolver 与重载/重启恢复，以及公开数据无环境值。全量检查、隔离真实子进程和浏览器后小步提交。

## 验收结果

11 个 driver/YAML 反例先失败，最终 873 测试 / 64 文件、build:all/typecheck/git diff --check 通过。真实离线子进程证明持有旧 resolver 仍输出角色 A，新 resolver 使用版本 2/角色 B；冷恢复旧审批 409、重跑新报告后仍等待人工。仅版本变化也使旧协调提议不可采用，新轮次恢复。

隔离 git 工作区真实 HTTP：同 argv、环境角色 A→B、context_revision 1→2，配置 hash 改变，旧报告重新生成，worker 总调用 2 次。后续重启未重复调用、审批 ID 保持、PRD 未变，人工决定/节点退出 0，doctor=true。公开清单仅显示数字版本与 hash，不包含环境值或环境报告内容。

Playwright/Chrome 1440/390/320 验证筛选后的上下文 v2、响应/页面无私有环境标记，无横向溢出/pageerror；桌面/手机截图已查看无重叠。仅本地 fixture 验收，不调用付费模型、不修改真实开发 Draft。该版本必须手工维护，不自动发现环境变化；CLI 行为和凭据有效性不由指纹认证。运行目录和截图不入库。
