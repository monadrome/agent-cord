# ADR-0064 ｜ Goal 验收条件与宿主证据覆盖

- 状态：accepted
- 日期：2026-10-09
- 关联：ADR-0055/0056（交付审计）、ADR-0061（ready 共用来源）、ADR-0044（协调验证观察）
- 来源：Goal 只运行命令和检查指南章节，没有显式验收条件到实测证据的映射

## 背景

一组检查通过以及“变更/验收/风险”非空，不能让 reviewer 逐项确认验收条件对应哪些实际执行结果。模型可以写“已完成全部需求”，宿主却没有发布的条件清单或覆盖身份。需要把约定条件与宿主真实结果绑定，而不是由模型自己声明通过。

## 备选方案

1. 仅要求 worker 在 Markdown 中列验收清单，自报结果。
2. 由另一个模型解释 PRD 并判定所有业务条件完成，直接作为 gate 通过依据。
3. 发布 Goal 明确声明验收条件及检查 ID，宿主生成逐项实际证据，恢复/协调共用来源规则。

## 决策

采用方案 3。run.goal 可选 acceptance 数组，每项为 `{ id, criterion, checks }`，最多 16 项；id 是唯一稳定标识，criterion 是有界非空条件说明，checks 是唯一且非空的 Goal check ID 列表。声明 acceptance 时必须全部引用已声明检查，且每个声明检查至少属于一个条件；非法、空或不完整配置在发布/解析前拒绝。未声明保持既有 Goal 语义，不声称条件覆盖。

worker 上下文包含发布的条件与映射。宿主实际执行所有检查，完成审计通过后在指南中生成“宿主验收覆盖”表格，逐项列条件、检查、验证事件 ID 和真实通过状态。模型自报的矩阵不被读取为事实。ready payload 增加可选 acceptance_evidence：严格按发布顺序保存 `{ acceptance_id, verification_event_ids }`。有验收清单的新 ready 必须完整记录；旧无清单 ready 可无字段。有字段但无声明、未知/重复/遗漏/错序/失败或错误引用拒绝，不回退旧成功。

resolveGoalReadiness 在既有 worker/验证来源检查后验证完整映射，runner、恢复入口及协调投影共用。Goal 观察可选 acceptance_evidence 只传宿主来源的 ID 映射，并受 current/freshness_reason 约束；旧 hook/未声明不新增虚假覆盖。改变验收清单纳入 workflow/input 身份，使原证据/提议失效。

声明验收清单的 Goal post 人审消费与冷恢复等待同样核验合法 ready 来源；仅当前命令通过不足以绕过缺失的条件映射。pre gate 在 Goal 执行前按原语义处理，历史已退出节点不回滚。

宿主进展 hash 在绑定 acceptance 时包含未解决条件 ID 与必需检查失败集合；保持源码不变且失败集合/未解决条件不变才视为无进展。无声明保持原进展域，不能只靠指南文字变化延长预算。已经通过的结果仍绑定当前输入，测试失败或执行不全不记录覆盖通过。

示例/推荐 Goal 模板声明离线测试、类型检查和构建三项交付条件，明确这是最低工程基线，业务条件须在发布版本中补充对应检查。没有足够信息建立业务覆盖时不能把基线称作完整需求验收。

## 理由（第一性原理推导）

1. 用户给的是目标，完成审计必须能定位目标条件的执行证据，而非只看调用结束或章节结构。
2. 判定权留在宿主，模型和 reviewer 都能引用同一组条件/测试事件，恢复语义保持一致。
3. 显式发布契约可审计且兼容旧流程，不引入一套模型打分或独立推进状态机。

## 被否方案的否决理由（逐一）

- 方案 1：worker 自报无法证明实际执行和当前源码身份。
- 方案 2：模型语义判断不能证明实测，且会把不确定业务完成自动升级为通过事实。
- 把测试绿当全部业务完成：检查覆盖范围必须由契约与人审确认，不能从绿色状态推断。

## 关键实现注意点

1. 映射由宿主产生，引用已有 verification.completed，不新增伪测试事件。原命令输出/凭据不进入覆盖 payload。
2. Markdown 表格使用转义处理条件文本；条件内容不作为解析 marker 或命令执行。
3. 顺序和全集一致性在共享解析器核验，失败最新证据不能回退之前成功。当前输入和指南仍须重读。
4. 成功/未知检查/重复/缺项/错引用/失败/代码变化/冷恢复/ACP-headless 真子进程均须覆盖；happy path 不增加人工中途步骤。
5. 覆盖只证明“声明的条件关联实际检查并通过”，不证明测试对条件的逻辑充分性、抗篡改或所有 PRD 语义均被声明。最终 review 保留。
